# Ограниченный поиск отображения

`src/soft_isomorphism/search.py` реализует два режима над одной стоимостью
из [задачи #15](matching-cost.md):

- `exhaustive_search` перечисляет все допустимые отображения для проверки графов
  до 5 узлов и не более 3 кандидатов на узел;
- `beam_search` упорядочивает узлы по степени и ID, расширяет отображение
  допустимым кандидатом либо `null`, оставляет 64 лучших частичных состояний,
  останавливается после 50 000 расширений, возвращает до 10 полных отображений.

Частичная оценка включает только уже неизбежные неотрицательные штрафы.
Отсечение по ширине beam лишает гарантии оптимума: флаг
`optimal_within_candidates` тогда ложен. При полном перечислении без отсечения
он истинен **только для переданных списков кандидатов**, а не для всего KG.
`budget_exhausted` и `no_feasible_mapping` возвращаются явно, без подмены
несуществующим соответствием. Результат содержит стоимости по компонентам,
mapping, время и число расширенных состояний. Проверка с полным перебором,
направлением ребра, узким beam и лимитом расширений входит в `make check`.

Вызов на реальном KG требует отдельной генерации кандидатов из задачи #13.
