# Аналоги: таблица для слайда

| Метод | Вход → результат | Поиск | Предел для нашего вопроса |
|---|---|---|---|
| [SimGRAG](https://aclanthology.org/2025.findings-acl.163.pdf) | Claim/вопрос → pattern → KG subgraph → вердикт/ответ | GSD и top-k с отсечениями | Требует структурного соответствия pattern и найденного графа; релевантен FactKG |
| [NGM-RAG](https://arxiv.org/pdf/2607.11159) | Вопрос + граф корпуса → evidence → ответ | Лексика + GNN, top-k узлов | Релевантен HotpotQA, но другой тип графа и нет общего воспроизведённого запуска |
| [NeMa](https://www.vldb.org/pvldb/vol6/p181-khan.pdf) | Граф-запрос → top-k приблизительных совпадений | Мягкие штрафы за метки и окружение | Показывает, что soft graph matching уже известен; QA не оценивает |

Открытый вопрос: помогает ли учитывать согласованность извлечения рёбер при поиске
доказательств для проверки claim по KG? Проверим E1 против B3 при одинаковых входных
графах, кандидатах и reader. Это гипотеза, а не заявленное преимущество.
