GraphRAG](https://arxiv.org/abs/2404.16130) | 2024 | | Граф сущностей/отношений → communities → summaries → query-focused ответ | Превосходит классический RAG на глобальных вопросах по корпусу | Задаёт контекст: зачем нужна графовая структура, почему классического RAG недостаточно | |
| [Cai et al. SimGRAG](https://arxiv.org/abs/2412.15272) | 2024 | | Текстовый запрос → граф-паттерн (LLM) → поиск подграфов по GSD | GSD позволяет комбинировать структурное и семантическое сходство при поиске в KG | Ближайший аналог; наш подход заменяет текстовый запрос на граф документа | |
| [Liu et al. KnowFormer](https://arxiv.org/abs/2409.12865) | 2024 | | Transformer с message-passing для reasoning над KG; structure-aware attention | Превосходит path-based методы на transductive и inductive бенчмарках | Формализация graph isomorphism через биекцию + WL-тест — теоретическая база | |
| [Chen et al. PolyRAG](https://arxiv.org/abs/2407.21276) | 2025 | | Каскадный retrieval: онтология → KG → raw text | +395% F1 vs GPT-4 baseline; outperforms 19 SOTA на academic и financial QA | Перспектива многоуровневой организации знаний; косвенно связана с задачей | |
| [Li et al. SubgraphRAG](https://arxiv.org/abs/2410.20724) | ICLR 2025 | | Lightweight MLP скорит тройки параллельно; encodes directional structural distances; subgraph size tunable | GPT-4o достигает SOTA на WebQSP и CWQ без fine-tuning; Llama3.1-8B конкурентоспособен | SOTA на тех же бенчмарках что SimGRAG; показывает, что простой скоринг троек эффективен | |
| [Chen et al. NGM-RAG](https://arxiv.org/abs/2607.11159) | 2026 | | Граф из данных → нейронный graph matching (GNN + text) → adaptive node weighting → генерация | Превосходит GraphRAG и LightRAG на multi-hop QA и long-context summarization | Прямой конкурент: тот же класс задач (graph matching + RAG); входная точка — граф, не текст | |
| [Zhang et al. Graph RAG Survey](https://arxiv.org/abs/2501.13958) | 2025 (v3: сен 2025) | | Систематический обзор: graph indexing → graph retrieval → structure-aware generation | Охватывает методы, домены, открытые проблемы; поддерживается Awesome-GraphRAG репо | Закрывает knowledge gap: даёт картину существующих подходов и место SimGRAG/NGM-RAG в ней | |
| [Luo et al. GFM-RAG](https://arxiv.org/abs/2502.01113) | NeurIPS 2025 | | GNN-ретривер (~8M параметров) поверх KG-индекса; предобучен на 60 KG / 14M троек; query-dependent retrieval | SOTA на 3 multi-hop QA и 7 domain RAG датасетах без fine-tuning; neural scaling laws | Прямой конкурент: GNN для ретривала из KG без явного graph matching; новейший бейзлайн | |
| [Wang et al. GPR](https://arxiv.org/abs/2506.00261) | EMNLP 2025 | | Graph-Pretrained Retriever: LLM генерирует синтетические вопросы из троек (masked triplet prompting) + structure-aware objective | Улучшает downstream generation на WebQSP и CWQ vs text-pretrained retrievers | Конкурент по retrieval-side; показывает ценность graph-специфичного pretraining | |
| [Kim et al. FactKG](https://arxiv.org/abs/2305.06590) | ACL 2023 | | 108k claims из DBpedia; 5 типов reasoning: One-hop, Conjunction, Existence, Multi-hop, Negation; задача fact verification | Первый KG-based fact verification датасет с multi-hop natural language claims | Кандидат датасет: содержит document→KG mapping, multi-hop структуры, публично доступен | |
| [Ho et al. 2WikiMultiHopQA](https://arxiv.org/abs/2011.01060) | COLING 2020 | | Wikipedia + Wikidata; шаблоны + логические правила; каждый пример содержит reasoning path | Требует multi-hop reasoning; модели не могут срезать путь через text shortcuts | Кандидат датасет: структурированные reasoning paths = потенциальный document graph; Wikidata как KG | |
| [Tan et al. Re-DocRED](https://arxiv.org/abs/2205.12696) | EMNLP 2022 | | Переразметка 4053 DocRED-документов: добавлены пропущенные relation triples, исправлены coreference ошибки | +13 F1 vs оригинального DocRED; исправлены систематические false negatives | Кандидат датасет: document-level relation extraction с KG-связями (Wikidata); нетривиальные структуры | |
| [Raj et al. Charting Design Space](https://arxiv.org/abs/2510.22897) | ICLR 2025 | | Дизайн-пространство нейронных subgraph matching: early vs late interaction, node/edge embeddings; сравнение на GNN-архитектурах | Показывает, что выбор interaction scheme критичен; поддерживает разработку soft iso метрики | Теоретическая база: даёт систематику подходов к soft subgraph matching — прямой входной материал для нашей метрики | |
