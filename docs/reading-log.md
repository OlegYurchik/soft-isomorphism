| [Li et al. SubgraphRAG](https://arxiv.org/abs/2410.20724) | ICLR 2025 | | Lightweight MLP скорит тройки параллельно; encodes directional structural distances; subgraph size tunable | GPT-4o достигает SOTA на WebQSP и CWQ без fine-tuning; Llama3.1-8B конкурентоспособен | SOTA на тех же бенчмарках что SimGRAG; показывает, что простой скоринг троек эффективен | |
| [Chen et al. | [Zhang et al. Graph RAG Survey](https://arxiv.org/abs/2501.13958) | 2025 (v3: сен 2025) | | Систематический обзор: graph indexing → graph retrieval → structure-aware generation | Охватывает методы, домены, открытые проблемы; поддерживается Awesome-GraphRAG репо | Закрывает knowledge gap: даёт картину существующих подходов и место SimGRAG/NGM-RAG в ней | |
| [Lee et al. SAFE](https://aclanthology.org/2025.emnlp-main.883/) | 2025 | Есть ли до нас явная релаксация query edge → KG path? | LLM pseudo-query graph → Approximate Distance Join: edge удовлетворяется path длины ≤ δ → ranked semantic subgraph matching; schema graph служит distance oracle | Улучшает accuracy и efficiency на WebQSP, CWQ и GrailQA | Прямо пересекается с нашей edge-to-path релаксацией; широкая формулировка новизны уже занята | Критически важная ближайшая работа |
| [Wang et al. MGRAG](https://doi.org/10.14778/3819518.3819565) | 2026 | Есть ли работа, объединяющая ленивое построение графа и semantic path matching? | Query-specific KG строится lazy top-down; query relation сопоставляется с агрегированным data-graph path; greedy semantic path growing | Улучшает эффективность и качество на семи multimodal QA datasets | Самый близкий механизм: одновременно lazy construction и path-based semantic subgraph matching | Обязательный conceptual reference; нашу новизну надо сузить |
| [Zhu et al. HyperPathsRAG](https://aclanthology.org/2026.findings-emnlp.1530/) | 2026 | Есть ли совместный path retrieval на HotpotQA? | Question decomposition в n-ary subquestions → совместное сопоставление с hypergraph facts → paths по chain completeness | Лучший средний EM на трёх backbones; HotpotQA/2Wiki/MuSiQue hard subsets | Очень близкая цель и benchmark, но иное hypergraph representation и multi-target matcher | Обязательный benchmark/path-retrieval reference |
| [Wu and Luo, TopoRAG](https://aclanthology.org/2026.findings-acl.1703/) | 2026 | Какие есть topology-aware альтернативы без query graph matching? | Diameter-constrained ANN непосредственно учитывает связность при выборе entities | Повышает precision и снижает context redundancy | Соседний topology-aware retrieval; не сопоставляет query edges с paths | Важный structural baseline class |
